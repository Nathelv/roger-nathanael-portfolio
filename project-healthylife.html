HealthyLife Hub

A web-based health education and monitoring platform that combines application functionality with structured data.

Project TypeAcademic Group Project
CourseProgramming for Business · Semester 3 (Odd 2025/2026)
Team6 members
RoleAI Chatbot & Login; several pages

The Problem

People need an accessible way to learn about healthy living and get quick answers to their health questions in one organized place, rather than scattered across sources.

The Solution

A web-based health education and monitoring platform offering articles, a health quiz for logged-in users, and an AI chatbot that answers health-related questions within defined constraints, plus admin tools to manage article content. The AI chatbot flow is: PHP → Gemini API → AI response → Chatbot UI.

My Contribution

I implemented the AI chatbot and the login functionality, and worked on several pages of the website.

Main Features

  • User Login & Admin Login
  • Articles & Admin Article Management
  • Health Quiz (restricted to logged-in users) & Quiz Result
  • AI Chatbot for health-related questions

Technology

HTMLCSSJavaScriptPHPMySQLXAMPPGemini APIVisual Studio Code

Process

Concept→ Layout & Design→ Coding→ Trial & Error Testing

The main challenge was CSS styling and layout, solved through iterative trial and error and adjustment.

Outcome

Core functionality was successfully implemented, including the AI chatbot, login, quiz, and admin article management — though article content was still incomplete.

What I Learned

  • How to integrate an external API (Gemini) into a PHP web application.
  • How to bring AI into a product feature — routing user questions to the model and returning safe, useful answers.
  • Teamwork and coordinating shared work across a multi-page website.
